## 项目名

**Mimesis · 拟态人格引擎**

`Mimesis`（拟态 / 模仿）取自亚里士多德《诗学》——艺术源于对现实的模仿。
选这个词而不是 "clone" 或 "chatbot"，是因为这个项目真正做的事不是"复制一个聊天机器人"，
而是**重建一个人的表达方式，再让它在一个真实的时间线里继续生活**：她会累、会熬夜、
会在军训期间抱怨腿酸、会知道下周放假——这些都不是训练出来的，是"活出来"的。

建议的仓库名：`mimesis-persona-engine`（备选：`EchoPersona` 回声人格 / `Doppel` 双生）。
