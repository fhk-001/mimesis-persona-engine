# 一、设计目的

## 1.1 缘起

起点很朴素：想让聊天软件里出现一个"像某个具体的人"的对话者，而不是一个什么都能聊、
但聊起来谁都不像的通用助手。

通用大模型的问题不在于不够聪明，而在于**太平均**：措辞完整、逻辑周全、情绪稳定，
每句话都像客服培训过的。而真实的人恰恰相反——句子短、没标点、爱连着发好几条、
一句话里三个语气词、"不知道""你管我"当挡箭牌、心情不好就只回两个字。

于是问题被拆成一句可执行的命题：

> 把"一个人的说话方式"从聊天记录里抽出来，变成可复用的数据，再让大模型按这份数据说话。

## 1.2 三个设计目标

做成之后，怎么判断它"成了"？定了三个可检验的标准。

### 目标一：像（语言指纹）

判定标准：把生成的消息和真实消息混在一起，熟人看不出哪句是机器发的。

拆成可量化的维度：

- 句长分布——均值 6.9 字、中位数 5 字、90 分位 11 字，短句（≤6 字）占 61.7%
- 标点习惯——**95.8% 的消息结尾不带任何标点**，逗号使用率 5.4%，几乎不用波浪号和省略号
- 语气词配比——吧(89) / 啊(48) / 呢(39) / 哦(24) / 噢(22) / 嘛(20) / 呀(15) / 哇(15)
- 连发节奏——平均一轮 3.66 条，最长 36 条，**67.8% 的情况会连发 2 条以上**
- 中英与数字混用——拉丁字符占 4.9%，数字占 7.8%（课程名、分数、金额随话题出现）

这些数字全部来自本地统计（不调用模型），是后续所有生成约束的"标尺"。

### 目标二：活（活在真实时间线上）

语料是**以前的**聊天记录，但人是在**现在**生活的。这一条最容易被忽略，也最致命。

早期版本会出现这样的对话：

```
对方：你现在在哪
它：机房
    上计算机导论呢
    台上那老师在念PPT
```

问题是：那几天她正在军训，学校 9 月 28 日才开课，**她根本不可能在上课**。
它说得越具体，越假。

所以第二个目标是：它必须知道"今天是几号、我在哪个阶段、接下来有什么日子"，
并且这套认知要**随真实时间推进**——军训结束就自然过渡到上课，放假就自然进入假期状态。

### 目标三：真（逻辑自洽，不编造）

判定标准：多轮对话里不出现自相矛盾；被问到不确定的事不编；同一个人设在不同轮次表现稳定。

这条是本项目里最难的一条，也是最花时间的一条。原因见
[04-踩坑与问题复盘.md](04-踩坑与问题复盘.md)：**模型会把自己上一轮说错的话当成事实**，
于是错误会自我强化。

## 1.3 非目标（明确不做什么）

划定边界比堆功能更重要。以下是有意不做的：

| 不做的 | 原因 |
| --- | --- |
| 做成通用助手 | 一旦允许"什么都能干"，说话方式立刻退回平均值 |
| 多人格 / 多角色切换 | 人格档案要为一个人调到极致，切换会互相污染 |
| 语音、图像、视频 | 语料只有文字，硬做反而降低可信度 |
| 用向量数据库做大而全的检索 | 数据量小（几百组对话），BM25 足够，且零依赖；实测向量化检索反而诱发"照抄原句" |
| 让机器人主动承认自己是 AI | 会破坏角色，但不允许它骗人——敏感问题的处理方式是"含糊过去"而非编造 |

## 1.4 关键取舍

项目里反复遇到"两个都想要但必须选一个"的地方，列出来供后来参考：

| 取舍 | 选择 | 理由 |
| --- | --- | --- |
| 速度 vs 质量 | 偏质量，但加了硬上限 | 一次回复要过"生成 → 质检 → 硬约束"三道关，宁可多花 2 秒也不能逻辑穿帮；但同时设 max_tokens、重复检测阈值，避免无限重写 |
| 风格 vs 逻辑 | 逻辑优先，但明确反对"话变干" | 中间有一版过度强调逻辑，结果回复变得冰冷机械。最终规则写成"逻辑是底线，但不能为了求稳把话说干——语气词、连发、口头禅必须保留" |
| 本地统计 vs 大模型判断 | 两者混合 | 统计负责"怎么说"（可量化、稳定），模型负责"什么人"（语义、需要理解）；本地统计的 n-gram 常把界面文字当口头禅，所以口头禅以模型给的为准 |
| 记忆越长越好 vs 越短越准 | 分层 | 短期 18 轮原文 + 长期事实（最多 12 条）+ 滚动摘要（每 12 条压缩） |
| 提示词 vs 程序化约束 | 两条都要 | 实测证明**纯提示词挡不住上下文污染**，所以关键约束必须有程序化兜底 |

## 1.5 验收标准

项目结束时用这套标准自查（对应 `python run.py selftest` 与体检脚本）：

1. 离线自检 10 项全过（不联网、不碰任何聊天软件）
2. 风格标尺可复现：同一份语料统计结果稳定
3. 阶段约束用例全对：该拦的说法拦住、正常的说法放过
4. 记忆库无"和当前阶段矛盾"的残留
5. 连续多轮实聊里，时间线自洽、不答非所问
6. 全部代码零第三方依赖即可跑通主流程

## 1.6 命名

**Mimesis · 拟态人格引擎**。

`Mimesis` 是亚里士多德《诗学》里的概念——艺术源于对现实的模仿。
它比 "clone" 精确：这个项目不是复制一个 chatbot，是重建**表达方式**，
再让它在真实时间线上继续生活。
