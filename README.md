# Mimesis · 拟态人格引擎

> 从聊天记录里重建一个人的表达人格，并让它活在真实的时间线上继续说话。

（原名：微信性格克隆聊天机器人）

一个能"变成某个具体的人"去聊天的机器人。

它做两件事：

1. **学人说话**：你把某人的聊天记录丢进去，它统计出这个人的说话习惯（句长、标点、口头禅、表情、连发习惯），再让大模型总结出性格档案，生成一份"人格档案"。
2. **替他聊天**：接到微信消息后，用这份人格 + 你的真实聊天语料 + 对话记忆，生成"像本人发的"回复，并按真人的节奏一条条发出去。

效果示例（左边是人，右边是克隆出来的机器人）：

```
朋友：在吗
机器人：在
机器人：咋了

朋友：晚上出来吃饭不？
机器人：去去去
机器人：几点啊

朋友：七点
机器人：好呀 那你过来接我
```

## 一、三条接入路线，先选一条

| 路线 | 用什么 | 优点 | 代价 / 风险 | 适合谁 |
| --- | --- | --- | --- | --- |
| **终端试聊** | 项目自带，不用装任何东西 | 五分钟就能看到人设像不像，完全不碰微信 | 不是真的发微信 | 所有人，**第一步都走这个** |
| **个人微信** | `wxauto` 操作电脑版微信（Windows） | 真的是你的微信号在聊，能接私聊和群 | 非官方自动化，有被限制/封号风险；需要微信保持登录、窗口不被最小化；对微信版本敏感 | 自己小号、测试、个人玩具 |
| **企业微信** | 官方回调接口 | 完全合规、稳定、不会封号 | 要注册企业微信、要公网回调地址（可内网穿透） | 想长期跑、给别人用 |

> 公众号路线也能做，但公众号不能主动给个人发消息（受 48 小时窗口限制），做"随时聊天"体验不好，所以没有做进去。

## 二、五分钟跑起来

### 1. 装 Python

项目核心只用 Python 标准库，**不需要 pip 装任何东西**。

去 [python.org](https://www.python.org/downloads/) 下载 Python 3.10 或更高版本，安装时勾选 **Add python.exe to PATH**。

装完在项目目录里执行：

```bash
python --version
```

> 嫌命令行麻烦的话：直接**双击项目里的 `run.cmd`**，它会自动找到 Python 并列出所有命令；
> 想试聊就双击后在同一个窗口敲 `run.cmd chat --persona personas/demo-linxiaoman --mock --fast`。
> 如果提示找不到 Python，说明安装时没勾「Add python.exe to PATH」，见文末常见问题。

### 2. 生成配置

```bash
python run.py init
```

会生成 `config.json`。打开它，把 `llm.api_key` 填成你的大模型 Key（也可以先留空，用离线模拟模式跑通流程）。

国内常用的填法：

| 供应商 | base_url | model 示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:14b` |

### 3. 先用自检确认环境没问题

```bash
python run.py selftest
```

用项目自带的假聊天记录跑一遍全流程（解析 → 统计 → 检索 → 生成 → 记忆 → 敏感词拦截）。全"通过"就说明代码没问题。

### 4. 用你自己的聊天记录生成人格

```bash
python run.py profile --chat 聊天记录.txt --me 要克隆的人的昵称
```

不知道昵称怎么写？先看一眼文件里都解析出了谁：

```bash
python run.py import --chat 聊天记录.txt
```

不想花钱，只想先看本地统计效果：

```bash
python run.py profile --chat 聊天记录.txt --me 张三 --no-llm
```

生成的文件在 `personas/default/`：

| 文件 | 作用 |
| --- | --- |
| `persona.json` | 人格档案，**可以直接手改**，觉得哪条不像本人就编辑它 |
| `system_prompt.txt` | 真正约束模型的完整提示词，想知道它凭什么这么说话就看这个 |
| `style_report.txt` | 语言风格统计报告（人话版） |
| `examples.json` | 从记录里抽出的"对方说 → 本人回"语料，聊天时会被检索出来当参考 |
| `meta.json` | 用了哪个文件、多少条记录生成的 |

### 5. 终端里试聊

```bash
python run.py chat
```

你扮演对方说话，机器人用克隆出来的人格回你。命令：

- `/prompt` 看完整人设提示词
- `/examples` 看这句话检索到了哪些真实语料
- `/facts` 看它记住了什么
- `/debug` 打开调试，看到每次送给模型的完整上下文
- `/exit` 退出

**建议先在这里聊十几轮**，把 `persona.json` 调到你满意，再上微信。不然微信里一开口就不像，返工更麻烦。

### 6. 接管个人微信（可选）

```bash
python -m pip install wxauto
python run.py wechat --check     # 先自检：能不能读到微信
python run.py wechat             # 默认演练模式，只打印不发送
python run.py wechat --live      # 确认无误后再真的发
```

默认是**演练模式**：它能收到消息、能生成回复、会打印出来，但不会真的发出去。跑一晚上看看它准备发什么，确认没问题再改 `config.json` 里的 `behavior.dry_run: false`。

## 三、它是怎么"复制性格"的

三层叠出来的，缺一层就会明显不像：

```
聊天记录 ──┬─→ ① 本地风格统计 ──→ 句长/标点/口头禅/连发习惯（硬指标，写进提示词强制执行）
           ├─→ ② 大模型性格分析 ──→ 性格、幽默方式、情绪模式、在意和回避的点
           └─→ ③ 真实语料库 ─────→ 每句话都从记录里找出最像的 3-5 组真实对话当参考

聊天时：
对方消息 ─→ 检索相似语料 ─→ 人设提示词 + 最近对话记忆 + 长期记忆 + 语料 ─→ 生成
         ─→ 去AI腔检查（像AI就重写一遍）
         ─→ 按本人习惯拆成 1-4 条 ─→ 按字数算打字延迟 ─→ 一条条发出去
```

几个让它"像"的关键设计：

- **只学语气，不照搬事实**：语料是当"语气参考"喂进去的，提示词里明确要求不要照搬里面的内容，避免它把旧事当成新事说出来。
- **长度匹配**：提示词里写死了"对方发短句你也回短句"。AI 最大的破绽就是不管你发什么它都回一长段。
- **拆条发送**：真人聊天是一条条蹦出来的。它会按句号/换行拆成多条，中间加上打字延迟。
- **故意不回**：`ignore_probability` 默认 0.08，大约 8% 的消息它会不回（就像真人看到但懒得回）。想让它句句必答就设成 0。
- **去 AI 腔**：生成后扫一遍"作为AI""很高兴为您""希望对您有帮助"这类词，命中就让它重写，再不行就把那几句删掉。
- **记得住事**：每 10 轮让模型从对话里抽出关于对方的客观事实（在准备考研、养了只猫、住哪），存进长期记忆，之后自然地用上。
- **敏感话题拦截**：命中"借钱/转账/验证码/身份证"等词直接不回复，等你人工处理。克隆人格最危险的用法就是被人骗钱，这道闸必须留着。

## 四、聊天记录怎么弄到

项目能自动识别这些格式，挑一个你能拿到的就行：

| 格式 | 说明 |
| --- | --- |
| 微信导出 txt | 每条消息是"昵称 时间"一行 + 正文，大多数电脑端导出工具是这个格式 |
| 单行 txt | `昵称 2024-03-02 21:14:07 你好` 或 `[2024-03-02 21:14:07] 昵称: 你好` |
| 最朴素格式 | `昵称: 你好` |
| CSV / TSV | 列名里含 sender/昵称/发送者、content/内容、time/时间 就能自动认出来 |
| JSON / JSONL | 字典数组，字段名同上，会自动匹配 |

支持的编码：UTF-8、GBK/GB18030、UTF-16 都会自动尝试。

### 如果只能导成图片（截图）

图片不能直接喂给程序，需要先转成文字。项目自带了这个工具，用的是 Windows 自带的 OCR，
**不需要联网、不需要装任何东西**：

#### 最省事的用法：一步搞定

1. 手机截好图，传到电脑上的**同一个文件夹**里（微信「文件传输助手」最快；不用管顺序，也不用改名）
2. 把这个文件夹**拖到 `投喂.cmd` 上**（或者双击 `投喂.cmd`，按提示粘贴路径）
3. 等它跑完 —— 它会自动识别新截图、把内容追加进语料、再用最新语料重新生成人设

几个贴心之处：

- **只有新图会被处理**：处理过的图记在 `work/feed.json` 里，重复投喂不会重跑老图
- **语料是累积的**：都追加到 `work/聊天记录.txt`，所以投喂越多、人设越准
- **大模型分析失败会保留原人设**：不会因为断网或额度不足把调好的人设覆盖成降级版
- 想从头再来：`python run.py feed --reset`

建议再把这个图标也拖到 C 盘（和「双击开聊」放一起），以后就是「拖图 → 双击聊天」两个动作。

#### 手动调用（可选）

1. 把聊天截图放进一个文件夹（png / jpg / bmp 都行，长截图不用裁）
2. 双击 `tools\ocr_images.cmd`，把文件夹路径拖进去回车；或者右键「使用 PowerShell 运行」

```powershell
powershell -ExecutionPolicy Bypass -File tools\ocr_chat_images.ps1 -Folder "D:\微信截图" -OutFile work\聊天记录.txt
```

它会识别每行文字，再按「对方气泡靠左、自己的靠右」自动判断谁说的，输出成程序能读的格式。
之后照常生成人格：`python run.py profile --chat work/聊天记录.txt --me 我`

几个调参项：

- **手机截图必加 `-PhoneLayout`**：自动裁掉状态栏、标题栏和输入框，并把图片放大 2 倍再识别。
  实测同一张截图，不加这个参数会混进 `发 息`、`．在线`、被拆成偏旁的怪字这类界面垃圾，
  加了之后 5 条消息全部干净，连"你"字都从误识别的"亻尔"变正确了
- 左右判断反了 → 加 `-SelfThreshold 0.5`
- 长截图被切断 → 加 `-SliceHeight 6000`
- 想给说话人起名 → 加 `-SelfName 我 -OtherName 张三`
- 截图字很小、错字多 → 加 `-Scale 3`

图片路线的代价（先知道再用）：**时间戳拿不到**，所以「活跃时段、回复速度」这两项统计会缺；
OCR 偶尔认错字（字越小越容易错）；表情包和图片消息完全丢失。
所以**只要那个导出工具能导出 txt/csv，就优先用文本**，图片是下策。

导出工具：电脑版微信配合开源的 `WeChatMsg`（留痕）等工具导出为 txt/csv 都行；手机端可以用微信自带的"聊天记录迁移"到电脑后再导出。

> 记录越多、越日常越好。**几百条以上**画像才立得住；只有几十条，性格分析基本靠猜。

## 五、让它上微信（变成你好友列表里的一个人）

要让机器人在微信里"成为一个好友"、你点它头像就能聊天，必须满足三个前提：

1. **一个小号**（第二个微信号）当机器人的身体——机器人不可能凭空出现在你的好友列表里
2. **电脑上装微信 3.9.X**，用小号登录，并保持在线
3. 机器人在这台电脑上跑，自动回复发给小号的消息

> **为什么必须 3.9 版？** wxauto 官方 README 写的是"微信 3.9.X"，
> 付费版 wxautox 也只写"3.9.8+"，WeChatFerry 的版本号同样是 39.x。
> 新的 4.x 客户端（进程名 `Weixin.exe`）目前没有成熟方案支持。
> 3.9 和 4.x 安装目录不同，**可以共存**：你自己继续用 4.x，机器人用 3.9。

### 步骤

**1. 装微信 3.9.X**

wxauto 官方 README 提供的下载（百度网盘，提取码 `vsmj`）：
`https://pan.baidu.com/s/1FvSw0Fk54GGvmQq8xSrNjA?pwd=vsmj`

装到默认目录即可，不要覆盖你现有的 4.x。下载完可以先验一下数字签名是不是腾讯的
（右键 exe → 属性 → 数字签名），或者把文件路径发我，我帮你验。

**2. 用小号登录 3.9 微信**

小号登录后，把它的昵称告诉我，我填进 `config.json` 的 `wechat.self_names`，
这样机器人就知道"哪些消息是自己发的"，不会自问自答。

**3. 装 wxauto**（它不在 PyPI 上，必须用 GitHub 安装）

```bash
python -m pip install git+https://github.com/cluic/wxauto.git
```

**4. 自检**

双击项目里的「**微信**」（或运行 `python run.py wechat --check`）。
它会告诉你 wxauto 装没装、能不能连上微信、读到了几个会话。

**5. 先演练，别急着真发**

```bash
python run.py wechat
```

默认是**演练模式**：能收到消息、能生成回复、会打印出来，但**不会真的发**。
用你自己的微信给小号发几条消息，看看它准备回什么。跑一天没问题再上线。

**6. 正式上线**

把 `config.json` 里的 `behavior.dry_run` 改成 `false`，或者启动时加 `--live`。

### 上微信后建议调的几个参数

| 参数 | 建议 |
| --- | --- |
| `behavior.whitelist` | 只回你自己的微信号，避免小号加到别人后乱回 |
| `behavior.max_replies_per_minute` | 默认 8，觉得太活跃就调到 4-5 |
| `behavior.ignore_probability` | 默认 0.08（约 8% 消息不回，更像真人），不想漏消息就设 0 |
| `behavior.active_hours` | 默认 8-23 点，半夜不回 |
| `wechat.self_names` | 填机器人小号的昵称 |

### 风险

自动化操作个人微信属于非官方用法，**有被限制或封号的风险**：
务必用**小号**、别群发、别主动加陌生人、把频率压住。
企业微信才是官方合规通道（见下面的对比表）。

### 走不通微信？用 QQ（推荐）

**背景**：2026-09 实测，腾讯已经不允许微信 3.9.x 客户端登录了
（扫码时会提示"版本过低请更新"，装的是官方正版也一样）。
而 wxauto / wxautox / WeChatFerry 全都依赖 3.9 客户端，所以微信这条路对新用户基本封死。

QQ 反而更顺：主流方案用的是 **NapCat**（基于你电脑上已有的 QQNT 客户端，不需要旧版），
同样能实现"小号变成好友、点开头像就能聊天"。

**步骤**

1. **准备一个 QQ 小号**（不要用主号，理由见下面的风险）
2. **装 NapCat**：去 NapCatQQ 的 Releases 下载 `NapCat.Shell.zip` 解压
   （或直接用 Windows 一键版，更省事）
3. **启动并登录**：双击解压目录里的 `launcher.bat`
   （Win10 用 `launcher-win10.bat`；也可以在命令行传入 QQ 号快速登录）
4. **在 NapCat 的 WebUI 里配置**（浏览器打开它提示的地址）：
   - 开启 **HTTP 服务**，端口 `3000`
   - 开启 **HTTP 上报**，地址填：`http://127.0.0.1:5700/onebot`
5. **启动机器人**：双击项目里的「**QQ**」→ 先自检 → 通过后开始接收消息
6. **用你的主 QQ 加小号为好友**，点开聊天就能跟它说话了

**配置项**（`config.json` 的 `onebot` 段）

| 字段 | 说明 |
| --- | --- |
| `api_base` | NapCat 的 HTTP 服务地址，默认 `http://127.0.0.1:3000` |
| `host` / `port` / `path` | 本程序接收上报的地址，默认 `127.0.0.1:5700/onebot` |
| `access_token` | 如果 NapCat 里设了 token，就填在这里 |

**风险**：QQ 协议端同样有风控，登录后可能被限制甚至封号。
务必用**小号**、别群发、别主动加陌生人，并把
`behavior.max_replies_per_minute` 压到 4-5。

## 六、配置说明（config.json）

### llm —— 用哪个模型

| 字段 | 说明 |
| --- | --- |
| `base_url` / `api_key` / `model` | 任何 OpenAI 兼容接口。`api_key` 支持写 `"$LLM_API_KEY"` 从环境变量读取，避免把密钥写进文件 |
| `temperature` | 建议 0.9-1.2。太低会变成"标准客服"，太高会胡言乱语 |
| `mock` | `true` 时完全不调模型，用离线占位回复，适合测试流程 |

### behavior —— 聊天行为（最重要的部分）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `dry_run` | `true` | **演练模式**：只打印不发送。务必先跑一段再关掉 |
| `min_delay` / `max_delay` | 1.2 / 8.0 | 每条消息的发送延迟区间（秒） |
| `typing_chars_per_second` | 4.5 | 模拟打字速度，字越多延迟越长 |
| `ignore_probability` | 0.08 | 不回复的概率，让它更像真人。设 0 就是句句必回 |
| `cooldown_seconds` | 2.0 | 同一会话的最小回复间隔 |
| `max_replies_per_minute` | 8 | 每分钟最多回几条，防刷屏、防风控 |
| `active_hours` | `[8, 23]` | 只在这个时间段回复，半夜不回消息 |
| `whitelist` / `blacklist` | 空 | 只回谁 / 绝不回谁（填昵称或备注名） |
| `groups_enabled` | `false` | 群里是否也回 |
| `groups_require_at` | `true` | 群里只有 @ 到才回 |
| `sensitive_action` | `handoff` | 命中敏感词时：`handoff` 不回复转人工，`reply` 照常回 |
| `sensitive_keywords` | 见文件 | 触发转人工的词，建议只加不减 |

### persona —— 人格与语气

| 字段 | 说明 |
| --- | --- |
| `dir` | 用哪个人格目录。可以建多个人格，用 `--persona` 切换 |
| `max_chars` | 单条回复的目标长度上限（字）。这是"像不像"的关键参数 |
| `split_long_replies` | 长回复是否拆成多条发 |
| `identity_disclosure` | `true` 时，被直接问"你是本人吗"会如实说自己是 AI 分身 |
| `extra_rules` | 追加你自己的硬规则，例如"绝对不提工作""多用哈哈" |

### 其他

- `memory.recent_turns`：带多少轮上下文进模型（越大越连贯，也越贵）
- `memory.long_term`：是否抽取并记住关于对方的事实
- `retrieval.top_k`：每次带几条真实语料做参考（4 条左右比较平衡）
- `wecom.*`：企业微信通道的 corp_id / secret / token / 回调地址配置

## 七、上微信之前，请先看这段

克隆别人说话，比普通机器人更容易越界。请守住三条线：

1. **要授权**。克隆的是别人的人格，本人同意才做。克隆自己也要注意——你的账号可能被人拿来说出你从没说过的话。
2. **别让它替本人做决定**。承诺、转账、表白、吵架这些事，让真人自己来。项目默认对钱和验证码相关的词直接不回复，别去关掉它。
3. **别骗人**。向亲友隐瞒"这是 AI"用于骗感情、骗钱，可能不只是道德问题。拿不准就打开 `identity_disclosure`，或者在微信备注里加一句"AI 分身"。

另外两个现实风险：

- **封号**：个人微信自动化属于非官方用法，微信有权限制。用小号、降低频率、别群发、别加陌生人。
- **错误信息**：它可能编造行程和事实。提示词里已经禁止它编造，但不能保证 100%，重要对话请自己复核。

## 八、常见问题

**Q：报错 `No module named wxauto`？**
`pip install wxauto`。个人微信通道需要它，其他三个通道都不需要。

**Q：提示 `python 不是内部或外部命令` / `无法将"python"项识别为 cmdlet`？**
说明装 Python 时没勾选「Add python.exe to PATH」。三种办法：① **双击项目根目录的 `setup-path.cmd`**，它会自动把 Python 加进你的用户环境变量（不需要管理员权限，只影响你自己的账户）；② 重新运行安装包，选 Modify，把「Add Python to environment variables」勾上；③ 或者每次用完整路径，例如
`& "$env:LOCALAPPDATA\Programs\Python\Python314\python.exe" run.py selftest`。
装好后新开的终端窗口才会生效，已经开着的窗口要重开。

**Q：`wechat --check` 报错连不上微信？**
按顺序查：① 电脑版微信是不是登录状态 ② 窗口有没有被最小化到托盘（wxauto 需要操作窗口）③ 微信版本。wxauto 历史上主要适配 3.9.x 桌面版微信，新版微信（4.x 的 Weixin 客户端）界面变化大，可能不被支持——这种情况请去 wxauto 项目文档确认当前支持的版本，或改用企业微信通道。你机器上装的是 4.1.13.65，属于新版客户端，需要重点确认这一点。

**Q：回复一点都不像怎么办？**
按这个顺序调：① 语料太少 → 多喂记录 ② `max_chars` 调到和本人平均句长一致（看 `style_report.txt`）③ 打开 `/prompt` 看提示词，把 `persona.json` 里不像的条目删掉、补上你观察到的习惯 ④ `temperature` 调到 1.0-1.2 ⑤ 在 `extra_rules` 里写死几条铁律。

**Q：会不会把我的聊天记录传出去？**
只有"生成人格"那一步会把**抽样后的语料片段**发给大模型服务商，`profile --no-llm` 可以完全不发。聊天时发出去的是当前对话上下文 + 检索到的几条语料。所有文件都存在你本地，不上传任何第三方。想彻底本地化就用 Ollama。

**Q：群里能用吗？**
能，但默认关闭。把 `groups_enabled` 改成 `true`，建议保留 `groups_require_at: true`，否则它会接所有人的话，很容易翻车。

**Q：能同时跑多个人的分身吗？**
可以。每个人跑一次 `profile --out personas/xxx`，然后用 `python run.py chat --persona personas/xxx` 切换。
